# ARES PATHFINDER — ChatGPT Work handoff (বাংলা)

এই ZIP বর্তমান full game নয়। এটি নতুন Work chat-কে existing source + approved visuals + PDF + video + audit একসঙ্গে দেওয়ার প্রস্তুত package।

## কীভাবে ব্যবহার করবে
1. ZIP ফাইলটি download করো।
2. ChatGPT-এ New Chat খোলো এবং mode menu থেকে **Work** নির্বাচন করো (যদি তোমার account-এ available থাকে)।
3. এই complete handoff ZIP attach করো। Work ZIP extract করতে না পারলে Windows-এ ZIP-এ right-click -> Extract All করে `SOURCE_CURRENT` folder, `DESIGN/MASTER_BLUEPRINT.pdf`, `DESIGN/APPROVED_UI`-এর চারটি image, এবং `WORK_START_PROMPT.txt` আলাদা attach করো।
4. `WORK_START_PROMPT.txt`-এর পুরো text copy-paste করে send করো।
5. Work-কে existing SOURCE_CURRENT directory থেকেই code edit/run/browser QA/export করতে বলো। User-এর ~5GB raw NASA TIFF upload দরকার নেই: 32 processed Jezero tiles already present in source.
6. Work result দিলে আগে browser-এর actual live gameplay দেখো। Final ZIP-এর পাশাপাশি build/test status চাইবে, conceptual ছবি নয়।

### জরুরি সতর্কতা
Work mode থেকেও output সত্যিই photoreal/complete হবে—এমন গ্যারান্টি নেই। কোনো model/audio/VR test না হলে 'NOT VERIFIED' বলা বাধ্যতামূলক। এই handoff package-এর মধ্যেই এমন একটি নির্দেশনা দেওয়া আছে।
