# Runtime screenshot provenance

`recovery_*.png` files are fresh, unedited captures of the running production application in a Linux Qt WebEngine browser using ANGLE SwiftShader. The address toolbar is intentionally retained. They are not concept images. `recovery_campaign_pass.png` shows the actual ten-stage runner result; scene review URLs use a separate QA save and are not claims of manually earned campaign progression.

`runtime_*.png` files come from the earlier build and are retained as historical evidence. They do not prove the recovered character heads, scanned-rock LOD or latest camera fix. The approved acceptance targets are under `DESIGN/APPROVED_UI`; none of these runtime captures establishes AAA visual acceptance.

Current campaign evidence is in `../runtime_campaign_recovery_final.json`. The later camera/spawn regression is in `../runtime_mission_ops_recovery.json`. Neither accelerated test timing nor software-renderer screenshots establish RTX/phone/headset performance.
