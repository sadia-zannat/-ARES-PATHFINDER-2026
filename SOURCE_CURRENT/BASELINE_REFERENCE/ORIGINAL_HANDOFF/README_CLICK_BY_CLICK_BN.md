# Windows Click-by-Click — ARES PATHFINDER

**শুধু এই ধাপগুলো করো; ৫ GB NASA TIFF আবার download/process করার প্রয়োজন নেই।**

1. `ARES_PATHFINDER_GAMEPLAY_INTEGRATION_2026.zip` download করো।
2. ZIP-এর ওপর Right-click > **Extract All** > Extract।
3. `ARES_PATHFINDER_GAMEPLAY_INTEGRATION_2026` নামের extracted folder খোলো।
4. `START_PATHFINDER_WINDOWS.bat` double-click করো। Chrome খোলা না হলে ঠিকানা `http://127.0.0.1:5186/` লিখো।
5. **START EXPEDITION** > Crew Select > **01 FIRST FOOTSTEPS**।
6. Mission target দেখার জন্য উপরে ডানদিকে zoomed circular map দেখো; keyboard `WASD` অথবা map-এর নিচের movement wheel ব্যবহার করো। Camera ঘোরাতে mouse drag, interaction-এর জন্য `E` অথবা **INTERACT**। `R` = rover, `M` = full map, `Shift` = run, `Space` = jump, `G` = route toggle।
7. প্রথম target-এ কাছে গিয়ে EVA checklist complete করো। এরপর ২টি survey point, flag + panorama এবং habitat return।

**নোট:** এটি upgraded source/gameplay integration build; তোমার reference screenshot-এর photo-real AAA final নয়। Official NASA audio বা AAA human rigging এই ZIP-এ নেই।

ভুল করে `PREPARE_REAL_TERRAIN_WINDOWS.bat` চালাবে না; tiles ইতিমধ্যে package-এ আছে। PowerShell-এ package install বা Vite/npm launch দরকার নেই।
